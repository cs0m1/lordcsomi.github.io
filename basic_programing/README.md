# PSUP Exam Prep

Programming practice tool with AI grading.

**Live site:** https://cs0m1.github.io/lordcsomi.github.io/programming_exam_prep/countdown/index.html

## Features

- 40 coding problems from course materials
- AI-powered grading (Gemini Flash)
- Auto-save sessions
- Multiple practice modes

## Setup

Open `countdown/index.html` or `coding_test/index.html`.

Configure Gemini API key when prompted (works without it using mock grading).

## Grading

- Correctness: 40pts
- Syntax & Quality: 40pts  
- Efficiency: 20pts
- Passing: 70/100

## Tech

Pure HTML/CSS/JS, localStorage, Gemini API.

## Privacy

All data stored locally in your browser. Nothing sent to external servers except Gemini API requests.

Mostly coded using Claude Opus 4.5.
