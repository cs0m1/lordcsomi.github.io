Project Description

An automated facial recognition and photo organization tool designed to process and group photos based on facial detection. The primary use case demonstrated is organizing photos from a "Szalagavato" (Hungarian graduation ceremony) event, making it easier to sort and categorize large collections of photos by the people appearing in them.

Technologies Used

  • Python (core programming language)
  • face_recognition library (for face detection and encoding)
  • PIL (Python Imaging Library) for image manipulation and drawing
  • OpenCV (computer vision library for image processing)
  • NumPy (for numerical operations on image data)
  • Pickle (for saving and loading processing state)
  • CSV (for metrics tracking and analysis)
  • Dash (for interactive web-based visualization)
  • Matplotlib (for statistical graphs and analysis)
  • Pandas (for data manipulation and analysis)

Key Features

Advanced Face Processing

  • Configurable face detection models (HOG or CNN)
  • Adjustable matching threshold for face similarity
  • Face location detection and encoding
  • Visual feedback with customizable bounding boxes
  • Specialized group photo handling

Smart Processing Features

  • Resume capability (saves state between runs)
  • Progress tracking with time estimation
  • Intelligent cleanup operations
  • Metrics collection and analysis
  • Folder structure optimization

Performance Optimization

  • Choice between fast (HOG) and accurate (CNN) detection models
  • Efficient face encoding and matching algorithms
  • Progress tracking with estimated time remaining

Data Analysis and Metrics

  • Detailed CSV metrics for each processed image
  • Track processing time, face counts, and match rates
  • Graph-based analysis of face relationships
  • Interactive visualization dashboard
  • Comprehensive statistical analysis

Technical Implementation

  • Face Detection: Uses the face_recognition library with support for both HOG and CNN models
  • Face Matching: Implements face distance calculations with configurable threshold
  • State Management: Utilizes pickle for saving processing state
  • Metrics Tracking: Records detailed processing metrics in CSV format
  • Image Handling: Uses PIL for image manipulation and drawing detection boxes
  • Error Handling: Robust error handling and progress tracking
  • Directory Management: Smart organization and optimization of photo collections
