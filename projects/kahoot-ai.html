KahootAI Assistant

JavaScript Chrome Extension Gemini AI HTML/CSS
Chrome Web Store

Project Description

A sophisticated browser extension that enhances the Kahoot learning experience by providing AI-powered answer suggestions through a minimalistic floating interface. The extension seamlessly integrates with Kahoot's platform to provide intelligent assistance while maintaining a non-intrusive user experience.

Technologies Used

  • JavaScript (ES6+)
  • Chrome Extension APIs
  • Google's Gemini AI API
  • HTML/CSS
  • Service Workers
  • GitHub Actions (CI/CD)

Key Features

Chrome Extension Architecture

  • Manifest V3 implementation
  • Background service worker for API handling
  • Content scripts for DOM manipulation
  • Options page for user configuration

AI Integration

  • Integration with Google's Gemini API
  • Local processing for privacy
  • Real-time answer analysis

User Interface

  • Floating indicator with customizable position (6 different locations)
  • Adjustable size (Small, Medium, Large)
  • Configurable opacity
  • Auto-hide functionality

Security & Privacy

  • Local storage for sensitive data
  • Limited domain permissions
  • No external data collection
  • Open-source codebase

Development Tools & Practices

  • Version Control: Git
  • Automated Deployment: GitHub Actions
  • Build Process: Automated ZIP generation
  • Testing: Chrome Extension testing environment
  • Documentation: Comprehensive README

Project Highlights

  • Universal compatibility with Kahoot games and challenges
  • Privacy-focused design with local processing
  • Automated release pipeline
  • MIT Licensed open-source project
  • Modular and maintainable codebase
