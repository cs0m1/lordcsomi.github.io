Moscow Metro Quiz Game

Node.js Express.js Socket.IO JavaScript Docker
Play Quiz

Project Description

An interactive multiplayer quiz application focused on testing knowledge about the Moscow Metro system. The project serves as an educational and entertaining platform where multiple players can compete in real-time to answer questions about one of the world's most famous metro systems.

Technologies Used

Backend

  • Node.js
  • Express.js (^4.18.2) - Web server framework
  • Socket.io (^4.6.1) - Real-time bidirectional communication
  • Nodemon (^3.1.7) - Development auto-reload utility

Frontend

  • HTML5
  • CSS3
  • Vanilla JavaScript
  • Socket.io Client

Deployment

  • Docker support
  • Fly.io deployment configuration

Key Features

Real-time Multiplayer

  • Supports multiple concurrent players
  • Live player joining/leaving updates
  • Synchronized quiz progression

Quiz System

  • 13 detailed questions about Moscow Metro
  • Multiple choice answers
  • Timed questions (30 seconds per question)
  • Score calculation based on answer speed
  • Maximum 1000 points per correct answer

Admin Interface

  • Control panel for game management
  • Ability to set expected number of players
  • Game start control
  • Player monitoring

User Experience

  • Real-time leaderboard updates
  • Waiting room for players
  • Immediate feedback on answers
  • Final podium display
  • Score tracking throughout the game

Project Structure

  • /admin - Admin interface files
  • /public - Public frontend files
  • /server - Backend server code
  • / - Root configuration files

Architecture

  • Client-server architecture using Express
  • WebSocket communication for real-time updates
  • Separate admin and user interfaces
  • Stateful game management system
